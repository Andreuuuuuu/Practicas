# Projecte de Pràctiques - Implantació d'Aplicacions Web

Benvingut/da al lloc de documentació de les pràctiques de **Implantació d'Aplicacions Web** de **2n ASIX**.

Aquest lloc recull totes les pràctiques realitzades durant el curs, documentades en format Markdown i publicades mitjançant **MkDocs** amb el tema **Material** i **GitHub Pages**.

## Objectius de la pràctica

- Configurar un entorn virtual de Python.
- Instal·lar Material for MkDocs amb pip.
- Escriure documentació en Markdown.
- Publicar el lloc a GitHub Pages.
